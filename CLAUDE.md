# CLAUDE.md

Antes de escribir o modificar cualquier código en este proyecto:

1. Lee `FOUNDATION.md` completo. Es la fuente de verdad de producto, branding, stack técnico y especificación funcional. Si tomas una decisión de diseño o alcance que no esté reflejada ahí, actualiza `FOUNDATION.md` antes de continuar.

2. Lee `SPRINTS.md` completo. Es el plan de desarrollo atomizado e incremental, con checkboxes de avance. Revisa cuál es el primer ítem sin marcar y continúa desde ahí — no adelantes sprints ni saltes validaciones.

3. Al terminar cada ítem de `SPRINTS.md`, márcalo como completado (`[x]`) antes de seguir con el siguiente. Actualiza también la línea de "Estado general" al inicio del archivo para reflejar el sprint actual.

4. No avances a un sprint nuevo sin haber confirmado (según el criterio de "Confirmar" de cada sprint) que el anterior corre correctamente.

Estos dos archivos, no el historial de la conversación, son la referencia de dónde va el proyecto.
